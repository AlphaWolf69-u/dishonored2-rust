# Flash UI (Iggy) runtime

The game's UI is RAD Iggy: AS3 movies in `.iggy` files with BC7 textures in
`.raw.iggytex`. The rewrite runs the installed movies in its own player.
Research notes live in `artifacts/ui-pause/notes-*.md` (local only).

| Location | Responsibility |
| --- | --- |
| `src/assets/iggy.rs` | `.iggy` container: header, sections, relocation programs (`FUN_141093380`). |
| `src/assets/iggy/` | Movie root, timelines/placements/SymbolClass, shapes/fills/bitmaps/iggytex index, fonts and edit text. |
| `src/assets/lang.rs` | Text language selection (`FUN_1400a3da0`, SKUConfig.txt, Steam mapping), string tables read like `FUN_140164a30`, localized library names. |
| `src/flash/avm2*` | AVM2 interpreter, builtins and the table-driven native class installer. |
| `src/flash/native_table.rs` | Generated from Iggy's registration (`FUN_14104cc40`) by `analysis/generate_native_table.py`. |
| `src/flash/*.rs` | Flash API ports: display list, timelines and Iggy's lifecycle, events, geometry, graphics, filters, timers, `IggyFunctions`. |
| `src/flash/text_engine.rs`, `text.rs` | Iggy's TextField engine: formats, font resolution and language aliases, HTML parser, line layout, relayout, autosize, draw pass. |
| `src/flash/three_d.rs` | Matrix3D from 3D properties, the Stage perspective projection. |
| `src/flash/keyboard.rs`, `mouse.rs` | Key events (`FUN_1410268f0`) and mouse targeting, over/roll/click/focus/wheel (`FUN_141021290` and callers). |
| `src/flash/render.rs`, `tessellate.rs` | Display list to triangle batches, 3D world composition and perspective-correct vertices. |
| `src/flash/raster.rs`, `src/bin/iggy_preview.rs` | CPU reference rasterizer and preview tool (`--pause-state` runs the game's pause steps). |
| `src/rendering/bevy_backend/flash_ui.rs` | GPU pass over the display output after post-processing. |
| `src/platform/bindings.rs` | Binding manager, config commands, `bindableActionsData` and key translation (tables generated by `analysis/generate_binding_tables.py`). |
| `src/gameplay/pause_state.rs`, `save_list.rs` | `arkGameLogicStatePause`: OnFlashLoaded, FillData, Show, notifications; save headers and the save/load lists. |
| `src/app/pause_menu.rs` | The client: PAUSE binding opens the state, game time pauses, keys and mouse reach the movie, `ResumeGame` closes it. The movie runs on its own thread. |

## Evidence rules

- Native class shapes (members, namespaces, constants, trivial handlers) come
  only from the generated table. A native Iggy implements without a Rust port
  is `MethodKind::Unimplemented` and fails with its address; the test
  `rust_natives_match_iggy_table` rejects Rust members Iggy does not declare.
- Startup and tick order follow `FUN_141028160` and `FUN_141021b40`
  (allocate-then-construct timeline children, post-order constructors,
  deferred gotos with modify placements applied at once, broadcasts in
  reverse registration order).
- The text language follows `arkLangSystem`; every installed language loads
  both pause movies (`pause_movies_load_in_every_installed_language`).

## Open questions and blockers

1. Error subclass construction: Error has a native constructor (0x14107ef30)
   but TypeError and the other subclasses register the IllegalOperationError
   stub. Whether `new TypeError()` reaches the stub is unresolved; the rewrite
   keeps Error's constructor. Next: trace the generic path of `FUN_141044820`
   past the type-tag switch, or break on 0x1410b38e0 in the running game.
2. `m_isLightVM` default: classes gated on `VM+0x6b40` are installed on the
   assumption that the pause decl's unset bit is 0. Next: read the decl
   default in `FUN_1404f2cd0` or the VM flag at runtime.
3. Rendering not yet ported: masks and clip layers, filters, blend modes
   beyond normal/add, cacheAsBitmap, the glyph bitmap cache, the exact curve
   flattening tolerance (`player+0x1e80`), game textures (save screenshots).
4. Game state the rewrite does not simulate yet, so the pause state writes
   what the game would for "unavailable": no save writer or loader (save,
   load and quick entries locked), no mission/chapter component
   (`chapterData`, restart lock), no tutorial log, no statistics component,
   no mission+ flag, no player character (`DH2_DEBUG_CHARACTER=emily`
   selects Emily's movie). Callbacks needing them (`CreateSave`,
   `LoadSave`, `QuickLoad`, `QuickSave`, `Restart`, `BackToMain`,
   `OnTutorialRead`, `DevGUI`) are logged as unhandled.
5. Options: `optionsData.sections` and the per-section data
   (`FUN_140516ed0` and the section classes) are not written yet; the
   Options screen stops in `OptionsScreen.initOpeningSequence`.
6. Message boxes (`MessageBoxRequest`, host movie `global.iggy`) are not
   hosted yet, so Quit/Restart confirmations do not appear.
7. Pause screen FX (`models/effects/gui/pause.fx`: `env/fx/ui_pause` with
   the `gui_pause_01_cc` colour cube and DOF, `r_skipDOF 0` while paused)
   is not applied. Open: which clock advances FX while the game clock is
   frozen (the clock step `FUN_1408af320` does not run in the paused frame
   `FUN_1408ad580`). Next: break on the env blend producer (21a240) during
   pause and read its time input.
8. Sound: `PostSoundEvent` and UI sound IDs (`_soundHandler.soundsList`)
   are not connected to audio.
9. Tab focus traversal on keyDown (`FUN_141027340`) and SimpleButton states
   (`FUN_1410279b0`) are not ported.
10. The PerspectiveProjection natives are approximations (fields as AS
    vars); rendering uses only the Stage projection, kept in player state.
11. `profile.bin` layout (pair count at 0x1a) is read from the file, not
    from a traced loader.
